obsidian-mcp-router — quick reference

v0.8.2 · multi-vault Obsidian MCP server + Claude Code plugin (30 slash commands)
github.com/tboome33/obsidian-mcp-router

The router in 30 seconds

A single MCP process that knows all your Obsidian vaults (local + remote). Each tool takes a vault parameter (or uses the default). No more registering one MCP server per vault.

  • One entry in ~/.claude.json → all vaults visible everywhere (Code + Desktop)
  • Local + remote vaults treated identically — drop URL + API key into the config, done
  • Cross-vault: vault: "*" auto-fans-out across every vault
  • Lock mode: restrict the session to a single vault (safety, focus)
  • Auto-enrichment (v0.8.2): Claude proactively suggests wiki saves at 3 moments (validation / result / topic switch)

Vault setup

  1. Have Node.js ≥ 20.18.1
  2. Install the Local REST API plugin in the Obsidian vault (community plugins)
  3. Optional for search_smart: Smart Connections + obsidian-mcp-router-bridge (from GitHub)
  4. Optional for Templater: Templater (community plugins)
  5. Auto-bootstrap the vault: 
    npm run setup-vault -- "C:\VAULTS\MyVault"
    ⇒ writes .env with VAULT_PATH, OBSIDIAN_API_KEY, OBSIDIAN_BASE_URL; allocates a unique port; adds to the registry.
  6. Verify: /obsidian-router:meta-status or just say "diagnose the router"

Configuration — environment variables (workspace .env)

VAULT_PATH Path of the current vault. Auto-detection: if it matches a registered vault, that vault becomes the default. Written by setup-vault.mjs.
OBSIDIAN_ROUTER_DEFAULT_VAULT Explicit override of the default vault for this process. Wins over VAULT_PATH and over config.defaultVault.
OBSIDIAN_ROUTER_LOCKED Locks the router to one vault for the session. Any tool call to another vault throws. Set via /obsidian-router:lock <vault> --persist.
OBSIDIAN_ROUTER_AUTO_ENRICH Wiki auto-enrichment mode: ClaudeAsk (default) | Hybrid | FullAuto | off. Set via /obsidian-router:auto-mode <Mode> --persist.
OBSIDIAN_ROUTER_NO_WATCH Disables hot-reload of the config file (useful for debugging).

Important files — where things live

~/.claude/obsidian-mcp-router/config.json Main router config (vaults, port registry, vault names, defaultVault, disabledVaults, remoteVaults). Hot-reload enabled.
~/.claude.json Claude Code/Desktop config. Must contain the mcpServers.obsidian-router entry pointing to the obsidian-mcp-router binary.
~/.claude/settings.json Activates the plugin (extraKnownMarketplaces + enabledPlugins) and optional hooks (SessionStart, PostCompact, Stop).
<workspace>/.env Environment variables for the current workspace (above). Auto-loaded at router boot.
<vault>/CLAUDE.md Vault wiki consigne — loaded by Claude Code into context. Includes the auto-enrichment consigne (4 modes) since v0.8.2.
<vault>/{index,log,hot,overview}.md Karpathy LLM-wiki structure (catalog, journal, hot cache, overview). Scaffolded by /obsidian-router:wiki.
obsidian-mcp-router/templates/wiki/CLAUDE.md Canonical template for the vault CLAUDE.md — cloned into every new vault scaffold.
obsidian-mcp-router/docs/auto-enrichment.md Full auto-enrichment guide EN+FR: 4 modes (use cases) + 4 placement channels.
