# === Deployment plan: vault "tribu" (mode: wg) ===

## docker-compose service

services:
  obsidian-tribu:
    image: lscr.io/linuxserver/obsidian:latest
    container_name: obsidian-tribu
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=Europe/Paris
      - "TITLE=Obsidian — tribu"
      - CUSTOM_USER=obsidian
      - "PASSWORD=<password>"
      - DISABLE_TERMINAL=true
      - DISABLE_ROOT=true
    volumes:
      - /srv/vaults/tribu:/config
    ports:
      - 127.0.0.1:28145:3001
      - 10.8.0.1:27145:27145
    shm_size: 1gb
    restart: unless-stopped

## nginx — REST API reverse proxy

(none for wg mode — the REST port is reached directly on the WireGuard interface; no nginx block needed.)

## nginx — Selkies GUI (web viewer) reverse proxy

server {
    listen 443 ssl http2;
    # self-signed cert — generate once: openssl req -x509 -newkey rsa:2048 -nodes \
    #   -keyout /etc/nginx/ssl/tribu.key -out /etc/nginx/ssl/tribu.crt -days 825 -subj "/CN=tribu"
    ssl_certificate     /etc/nginx/ssl/tribu.crt;
    ssl_certificate_key /etc/nginx/ssl/tribu.key;
    server_name tribu.kiviri.fr;

    # Self-heal on container IP-shuffle: re-resolve via Docker DNS every 10s
    resolver 127.0.0.11 valid=10s;
    set $upstream_tribu_gui obsidian-tribu;

    location / {
        # WireGuard-only — sensitive/medical GUI
        allow 10.8.0.0/24;
        deny all;
        # the container serves the GUI over HTTPS on 3001 (self-signed)
        proxy_pass https://$upstream_tribu_gui:3001;
        proxy_ssl_verify off;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_read_timeout 3600s;
    }
}

## router VAULT_* env line (add to the MCPHub instance env)

VAULT_TRIBU={"name":"tribu","baseUrl":"http://10.8.0.1:27145","apiKey":"<token>","description":"Mémoire IA famille","wireguard":true,"tlsInsecure":false,"timeoutMs":15000}

## notes

  - Vault "tribu" → mode wg; router reaches it at http://10.8.0.1:27145.
  - apiKey is a PLACEHOLDER — replace <token> with the vault's real Local REST API key before use.
  - GUI PASSWORD is a PLACEHOLDER — set a real one before exposing the GUI.
  - WG mode: REST port published on 10.8.0.1 (WG interface) — reachable only over the encrypted tunnel; ensure WireGuard is up on the host. No nginx needed for REST.
  - GUI port published on 127.0.0.1:28145 (unique per vault → no collision); nginx terminates TLS for the browser.
  - GUI viewer at https://tribu.kiviri.fr (nginx → container :3001).
  - tlsInsecure:false (verify TLS). Irrelevant here — REST is plain HTTP; pass --tls-insecure only if you later front the REST with a self-signed https endpoint.
